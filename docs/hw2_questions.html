Minimum Wages and Employment in New Jersey and Pennsylvania

Author

Peirong

Published

April 22, 2026

Introduction

In this post, I replicate key results from Card and Krueger (1994), Minimum Wages and Employment: A Case Study of the Fast-Food Industry in New Jersey and Pennsylvania.
On April 1, 1992, New Jersey increased its minimum wage from $4.25 to $5.05, while neighboring Pennsylvania did not. This setting allows a difference-in-differences (DiD) design: New Jersey stores are the treatment group, and Pennsylvania stores are the comparison group.

The assignment for option 3 asks us to replicate:

  1. Some of Table 2.
  2. Table 3 (the 9 numbers in rows 1-3 and columns 1-3).
  3. Table 4, column (i).

I follow the original data construction rules in the authors’ check.sas file.

df <- df %>%

    demp = emptot2 - emptot,
    dwage = wage_st2 - wage_st,
    gap = case_when(
      stater == 0 ~ 0,
      wage_st >= 5.05 ~ 0,

Something Additional

As an additional step, I plot the pre/post mean FTE employment in each state and annotate the DiD estimate.

plot_df <- data.frame(
  state = rep(c("Pennsylvania", "New Jersey"), each = 2),
  period = rep(c("Before (Wave 1)", "After (Wave 2)"), times = 2),
  mean_fte = c(row1_pa, row2_pa, row1_nj, row2_nj)
)

did_est <- (row2_nj - row1_nj) - (row2_pa - row1_pa)

ggplot(plot_df, aes(x = period, y = mean_fte, color = state, group = state)) +
  geom_line(linewidth = 1) +
  geom_point(size = 2.5) +
  labs(
    title = "Difference-in-Differences Visualization",
    subtitle = paste0("Estimated DiD effect = ", round(did_est, 3), " FTE workers"),
    x = NULL,
    y = "Average FTE Employment",
    color = "State"
  ) +
  theme_minimal(base_size = 12)

The figure makes the result intuitive: Pennsylvania employment declines while New Jersey employment slightly rises, yielding a positive DiD estimate.

Conclusion

This replication recovers the key findings requested in option 3:

  1. Table 2 (partial): means closely match the paper.
  2. Table 3 (9 numbers): replicated successfully, including a DiD of about 2.754.
  3. Table 4 column (i): NJ coefficient about 2.326 (SE 1.192), very close to the published estimate.

Overall, this supports the paper’s main conclusion that the 1992 New Jersey minimum-wage increase did not reduce fast-food employment relative to Pennsylvania in this sample.
