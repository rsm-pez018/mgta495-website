Key Drivers Analysis

Comparing correlation, linear-model, Shapley, Johnson, and random-forest driver measures

Author

Peirong

Published

June 10, 2026

1 Overview

This analysis uses customer satisfaction survey data to estimate which brand attributes are most strongly associated with overall satisfaction. I omit the polychoric correlations, as allowed in the assignment, and focus on these six measures:

  • Pearson correlation with satisfaction.
  • Standardized coefficient from a multiple linear regression.
  • Drop-one usefulness, measured as the full model R-squared minus the R-squared after removing one driver.
  • Exact Shapley values from a linear regression using R-squared as the fit metric.
  • Johnson’s relative weights, which decompose the same full-model R-squared.
  • Random forest mean decrease in Gini impurity.

The variables brand and id are identifiers rather than perceptual drivers, so I leave them out of the driver models.

3 Methods

Code 
model_r2 <- function(data, predictors) {
  if (length(predictors) == 0) {
    return(0)
  }

  fit <- lm(reformulate(predictors, response = "satisfaction"), data = data)
  summary(fit)$r.squared
}

shapley_r2 <- function(data, predictors) {
  p <- length(predictors)
  n_masks <- bitwShiftL(1L, p)
  r2_cache <- numeric(n_masks)

  popcount <- function(mask) {
    sum(as.integer(intToBits(mask))[seq_len(p)])
  }

  for (mask in 0:(n_masks - 1L)) {
    bits <- as.logical(sapply(
      0:(p - 1L),
      function(j) bitwAnd(mask, bitwShiftL(1L, j)) != 0L
    ))
    r2_cache[mask + 1L] <- model_r2(data, predictors[bits])
  }

  values <- setNames(numeric(p), predictors)

  for (j in seq_len(p)) {
    bit <- bitwShiftL(1L, j - 1L)

    for (mask in 0:(n_masks - 1L)) {
      if (bitwAnd(mask, bit) == 0L) {
        subset_size <- popcount(mask)
        weight <- factorial(subset_size) *
          factorial(p - subset_size - 1L) /
          factorial(p)

        values[j] <- values[j] +
          weight * (r2_cache[mask + bit + 1L] - r2_cache[mask + 1L])
      }
    }
  }

  values
}

johnson_relative_weights <- function(data, outcome, predictors) {
  x <- scale(data[, predictors])
  y <- as.numeric(scale(data[[outcome]]))

  predictor_cor <- cor(x)
  outcome_cor <- as.numeric(cor(x, y))
  eig <- eigen(predictor_cor)

  lambda <- eig$vectors %*%
    diag(sqrt(pmax(eig$values, 0))) %*%
    t(eig$vectors)

  beta_orthogonal <- solve(lambda, outcome_cor)
  weights <- as.vector((lambda^2) %*% (beta_orthogonal^2))

  setNames(weights, predictors)
}

For the linear methods, I fit satisfaction as a continuous outcome. For the random forest, I treat satisfaction as a five-class outcome and use impurity importance from ranger, which corresponds to mean decrease in Gini impurity for classification trees.

Code 
pearson_cor <- sapply(driver_vars, function(v) {
  cor(survey[[v]], survey$satisfaction)
})

standardized_data <- as.data.frame(scale(analysis_data))
standardized_fit <- lm(satisfaction ~ ., data = standardized_data)
standardized_beta <- coef(standardized_fit)[driver_vars]

full_model <- lm(reformulate(driver_vars, response = "satisfaction"), data = survey)
full_r2 <- summary(full_model)$r.squared

drop_one <- sapply(driver_vars, function(v) {
  reduced_r2 <- model_r2(survey, setdiff(driver_vars, v))
  full_r2 - reduced_r2
})

shapley_values <- shapley_r2(survey, driver_vars)
johnson_weights <- johnson_relative_weights(survey, "satisfaction", driver_vars)

rf_data <- survey |>
  select(satisfaction, all_of(driver_vars)) |>
  mutate(satisfaction = factor(satisfaction))

rf_fit <- ranger(
  satisfaction ~ .,
  data = rf_data,
  num.trees = 1000,
  importance = "impurity",
  seed = 495
)

rf_gini <- ranger::importance(rf_fit)[driver_vars]

driver_results <- tibble(
  variable = driver_vars,
  driver = unname(driver_names[driver_vars]),
  pearson = as.numeric(pearson_cor[driver_vars]),
  standardized_beta = as.numeric(standardized_beta[driver_vars]),
  drop_one = as.numeric(drop_one[driver_vars]),
  shapley = as.numeric(shapley_values[driver_vars]),
  johnson = as.numeric(johnson_weights[driver_vars]),
  rf_gini = as.numeric(rf_gini[driver_vars])
) |>
  mutate(
    pearson_rank = rank_desc(abs(pearson)),
    beta_rank = rank_desc(abs(standardized_beta)),
    drop_one_rank = rank_desc(drop_one),
    shapley_rank = rank_desc(shapley),
    johnson_rank = rank_desc(johnson),
    rf_rank = rank_desc(rf_gini),
    shapley_share = shapley / full_r2,
    johnson_share = johnson / full_r2,
    rf_share = rf_gini / sum(rf_gini)
  ) |>
  arrange(shapley_rank, driver)

The full linear model has an R-squared of 0.109. The exact Shapley values sum to 0.109, and Johnson’s relative weights sum to 0.109, so both methods decompose the same full-model fit.

The strongest drivers by the linear R-squared decompositions are Impact, Trust, and Service. These three drivers also have the highest Pearson correlations with satisfaction, which makes them the clearest top tier.

Some variables, especially Easy, Appealing, Build, and Rewarding, have positive simple correlations but much smaller standardized coefficients and drop-one values. That pattern suggests overlap among the drivers: they move with satisfaction, but they do not add as much unique explanatory power once the other attributes are already in the model.

The random forest Gini importance is noticeably flatter than the linear decompositions. This is not surprising here because all nine predictors are binary and the outcome has only five satisfaction classes. The linear methods give a sharper story: Impact and Trust are the first priorities, with Service as a close third.

6 Conclusion

Across the methods, I would prioritize Impact, Trust, and Service as the main satisfaction drivers. Appealing and Easy still matter directionally, but their lower unique contribution means they are more likely to be secondary or overlapping signals rather than the strongest independent levers.

The practical recommendation is to focus first on improving perceptions that the brand has meaningful impact, is trustworthy, and provides good service. These attributes are most consistently connected with higher satisfaction in both the simple association measures and the linear importance decompositions.
